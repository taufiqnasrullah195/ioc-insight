Design notes
  • Two modes, one binary: iocinsight 8.8.8.8 = one-shot (scripting, pipe) · iocinsight = interactive TUI menu
  • TUI library: textual (Python) — real menus, keyboard nav, mouse support, bukan print statis
  • Settings menu: switch language EN/DE/ID, toggle AI on/off, clear cache — persisted to config.yaml
  • Analyzer Status: remaining API quota per provider (VT 4 req/min free tier), last error, latency
  • History menu: searchable list, re-open past verdicts, export all to CSV
