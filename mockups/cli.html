Command reference
iocinsight <ioc> # single lookup, auto-detect type
--lang en|de|id # report language (default: en)
--file iocs.txt # bulk lookup, one IOC per line
--json # machine-readable output (pipe-friendly)
--no-ai # skip AI layer, deterministic score only
--no-cache # force fresh lookups
--copy # copy ticket report to clipboard
